Credits

Who makes Pokémon Origin Jade and which projects it is built on.

Origin Jade

Pokémon Origin Jade is a project by:

  • xMyDayyy
  • PekingEnte – graphics, including the title screen artwork, and this documentation website

What Origin Jade is built on

Pokémon Heart & Soul

Version 2.0.6 by the HnS team – the direct base of Origin Jade. Johto comes from it.

Modern Emerald

By resetes12 – the base Heart & Soul was first built on.

pokeemerald-expansion

By RHH (Rom Hacking Hideout), version 1.15.1 with later changes and selected fixes up to 1.17.1.

pokeemerald

By pret – the foundation all of these projects build on.

Note

If you build on Origin Jade, please credit Origin Jade and keep the whole chain: Pokémon Heart & Soul, Modern Emerald, RHH's pokeemerald-expansion with its version number, and pokeemerald.
